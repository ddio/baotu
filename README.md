# 堡圖

以 1901 年臺灣「二十廳」為地圖的即時佔地遊戲，單機、純靜態網頁。

網站：<https://baotu.ddio.io>

## 玩法

- 從自己的區拖到目標區派兵，一次把該區的兵全部派出去；派兵後該區要冷卻一下才能再派。
- 兵沿著相鄰的區走，會自己找路（拉線時看得到）：穿過自己的領地，到路上第一個不是自己的區開打。翻越中央山脈的路很慢；澎湖和紅頭嶼只能走航線，澎湖往臺北那條險航線一樣慢。
- 兩支敵對的軍隊在地圖上靠近了就會停下來打（不一定要在同一條路上）：一兵換一兵，每秒各少 20 個，看得到隊伍一點一點變少。打完了，兵多的那邊帶著剩下的繼續走。
- 到了別人的區，兵停在城外開打：雙方一個換一個，每秒各少 10 個，看得到數字往下掉。守軍先打光，剩下的兵就進城佔領。進城也要排隊（增援自己的區也一樣），每秒進 30 個，比圍城快。各區有自己的特色（大城、砲台、糧倉、驛站）。
- 每一局都有自己的網址（像 `https://baotu.ddio.io/#g=2-13-3n-wdlgnb`）：暫停、結束或重播時按「分享開局」，別人打開就是同一個開局，起點、對手數、難度、電腦用的亂數都一樣。
- 把所有對手清光就贏。每一局都會留下記錄（存在瀏覽器裡，最多 32 筆），可以重播；重播時圖角會跳出小紙條：你攻下、失守的據點，還有折損慘重的大仗（攻城失利、守住、路上遭遇）；重播時一樣可以「分享開局」。

## 開發

```sh
npm install
npm run dev        # 開發伺服器
npm test           # 規則與重播的測試
npm run build      # 型別檢查＋產生 dist/
npm run build:map  # 由鄉鎮界重新產生地圖資料
npm run balance    # 讓電腦互打幾百局，印出各難度的勝率（調數值用）
npm run duel       # 改電腦的打法時：讓新的「強」跟前一版對打，看有沒有變強、一局有沒有被拖長
npm run starts     # 每個起點各打一批，印出從哪裡開局比較吃香
npm run freeze     # 改規則之前：把現行的規則引擎凍結起來，舊記錄才能繼續重播
npm run freeze:map # 改地圖之前：把現行的地圖留一份，理由一樣
npm run fixture    # 改規則之後：替新版存一筆測試用的記錄
```

推上 `main` 之後，GitHub Actions 會跑測試、建置，再放上 GitHub Pages。

## 目前的限制

- 只能用滑鼠或觸控玩，還不能只靠鍵盤操作。
- 記錄只存在當下這個瀏覽器；換裝置要用「匯出／匯入」。
- 規則 v6 以後的記錄，規則或地圖改版了也能重播（用當時那一版的規則和地圖）；更早的記錄會留在清單裡，但不能重播。

設計上的決定與理由見 [docs/DESIGN.md](docs/DESIGN.md)。

## 使用統計

網站用 [GoatCounter](https://www.goatcounter.com/) 統計造訪人數，另外記下面幾種次數。不用 cookie，不記是誰；對戰的內容和記錄不會送出去。

| 什麼時候 | 記成 |
|---|---|
| 開了一局 | `play/<難度>/<對手數>/v<規則版本>` |
| 一局結束 | `end/<win｜lose｜quit>/<難度>/<對手數>/v<規則版本>` |
| 看了一筆重播 | `replay/v<那筆記錄的規則版本>` |
| 按了「分享開局」 | `share/send` |
| 照分享的開局（網址帶著代碼）開了一局 | `share/play` |

難度是 `easy`、`normal`、`hard`；`quit` 是中途按了重來或回主畫面，直接關掉分頁的不會有結束那一筆。程式在 `src/ui/track.ts`，站台代碼（`baotu.goatcounter.com`）寫在 `index.html`。自己架一份的話，把 `index.html` 最後那行 `<script data-goatcounter=…>` 換成自己的代碼，或整行拿掉（拿掉後遊戲照常運作）。

## 地圖與出處

- 區界資料來自 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（MIT 授權，資料源自內政部）。
- 地圖是**改編**，不是嚴謹的歷史地圖：用現代鄉鎮界近似 1901 年的二十廳，東部另依 1909 年的劃法切出花蓮港廳，再把紅頭嶼（今蘭嶼）從臺東分出來，共 22 區。對照表在 `tools/taiwan1901.config.mjs`。
- 以下歸屬是推定、未查到明確依據：三灣與竹南（歸新竹廳）、平溪（歸基隆廳）；高山地區（桃源、那瑪夏、茂林、烏來等）依地理位置歸入鄰近的廳。跨廳的鄉鎮整個歸給主要的一邊。
- 紅頭嶼獨立成一區是為了玩法（東南角多一個海上的據點），當年沒有這個廳；日治時期它屬臺東廳，1901 年當下的歸屬沒查到明確依據。
- 航線是遊戲的設定，不是照當年的定期航線畫的：澎湖到鹽水港、臺南、鳳山，紅頭嶼到臺東、恆春，以及澎湖沿西海岸到臺北的險航線。
- 有幾條連線在圖上是彎的（例如新竹—臺中的山路走內山、基隆—宜蘭沿海岸），是為了不從第三個據點的城門口穿過去，不是照當年的道路畫的。
- 澎湖在畫面上往本島靠近了一些，好讓手機放得下。
